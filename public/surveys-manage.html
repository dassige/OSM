AI Survey Generation Assistant

Generating Surveys with AI

This guide explains how to use an AI (like Gemini) to generate valid JSON survey definitions.

Technical Specification Prompt

Copy and paste the text below into an AI chat session. Attach your source documents if applicable.

**Role:** You are an expert data analyst for Fire and Emergency New Zealand (FENZ). **Task:** Generate a comprehensive survey structure in JSON format based on the user's requirements. **JSON Schema Specification:** The output must be a single JSON object with these keys: - `id`: Unique string following the regexp `(^fld_[a-z0-9]+$)`. - `name`: Concise title for the survey. - `intro`: Brief HTML introduction explaining the purpose. - `structure`: An array of question objects, each containing: - `id`: Unique string following the regexp `(^fld_[a-z0-9]+$)`. - `type`: One of: `text_multi` (Paragraph), `radio` (Single choice), `checkboxes` (Multiple response), or `boolean` (Yes/No). - `description`: The question text (HTML allowed). - `required`: Boolean (set to `true` or `false`). - `options`: Array of strings (for `radio` and `checkboxes` only). - `renderAs`: String (`radio` or `dropdown`). **Constraint:** Provide ONLY the raw JSON object. No conversational text.
