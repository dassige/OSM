System Tools

Knowledge Base

Rotate Document Links

Assigns a new GUID to every Knowledge Base document, immediately invalidating all previously shared public links. Use this periodically or whenever you suspect a link has been shared with unintended recipients.

⚠ All existing /knowledgebase/<guid> URLs will stop working. Members who have bookmarked or saved links will need new ones.

The stored documents themselves are not affected — only their access URLs change. Links embedded in forms and surveys resolve dynamically via the document ID and will update automatically.

Find Documents with Missing Files

Scans every Knowledge Base document record and checks whether its physical file is present in the configured storage backend. Useful after a database-only restore, a storage migration, or if files were deleted outside the application.

All documents are scanned regardless of their active/inactive status. The scan is read-only — no records are modified.

AI Evaluator Test Lab

Ad-hoc testing for AI grading logic. Fields auto-save to your user profile.

API Key Management

API keys allow external systems to authenticate to the REST API using the X-API-Key request header. Keys are never shown again after creation.
