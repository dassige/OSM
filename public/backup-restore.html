Scheduled Backup

⚠ Scheduled backups are not available on this deployment.

This server is running on an deployment. Ephemeral platforms (Cloud Run, App Runner, Fargate) may be scaled to zero between requests, so a server-side scheduler cannot guarantee it will fire on time. Use an external scheduler (Cloud Scheduler, EventBridge, cron on a persistent machine) calling GET /api/system/backup with an API key instead.
