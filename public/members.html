CSV Import — Members

Comma-separated (.csv) file with a header row. Column order does not matter. Wrap any value containing a comma in double quotes.

Column Status Values / Default
name Required Full name. Use quotes if it contains a comma.
email Optional Email address
mobile Optional Mobile number (e.g. 0211234567)
messengerId Optional WhatsApp phone number or identifier
enabled Optional true or false — default: true
notificationPreference Optional email, whatsapp, or both — default: email

Example

name,email,mobile,messengerId,enabled,notificationPreference "Doe, John",john@example.com,0211234567,fb_123,true,email
