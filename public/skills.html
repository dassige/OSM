CSV Import — Skills

Comma-separated (.csv) file with a header row. Column order does not matter. Wrap any value containing a comma in double quotes.

Column Status Values / Default
name Required Exact skill name as it appears in the OSM dashboard.
url Optional Link to skill resource or verification form
url_type Optional external or embedded — default: external
critical_skill Optional true or false — default: false
enabled Optional true or false — default: true

Example

name,url,url_type,critical_skill,enabled OI (IS1) - Operational Safety,https://example.com/skill,external,false,true
